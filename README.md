
# Nexora Technologies – Digital Solutions Website

A modern, responsive technology company landing page built with HTML, CSS, and JavaScript as part of Task 6 of the SAIKET SYSTEMS Front-End Development Internship.

## Project Overview

Nexora Technologies is a fictional technology company created to demonstrate the design and development of a professional business website.

The website showcases the company's services, introduces the business, highlights its strengths, and provides a contact form for visitors.

## Live Demo

Visit the live website:

[**Nexora Technologies – Live Website**](https://liberty1703.github.io/saiket-task-06-nexora-website/)

## Features

- Responsive design for desktop, tablet, and mobile devices.
- Navigation bar with a functional mobile menu.
- Hero section with a technology-themed illustration.
- About section introducing the company.
- Services section showcasing three core services.
- Why Choose Us section highlighting the company's strengths.
- Contact form with input validation and submission feedback.
- Contact information with clickable email and phone links.
- Responsive footer with quick navigation links.

## Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, animations, and responsiveness.
- **JavaScript** – Mobile menu interaction and contact form validation.
